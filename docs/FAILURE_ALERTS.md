# Уведомления об ошибках транзакций

Celery Beat каждые пять минут ищет транзакции со статусом `failed`, для
которых ещё не было успешного уведомления. Если VK-бот настроен, пользователю
отправляется сообщение с ID операции, временем получения, причиной ошибки и
командой ручного повторного запуска.

Оригинальный текст банковского СМС в уведомление не попадает. Причина ошибки
нормализуется и ограничивается 500 символами.

После успешной отправки в `failure_notified_at` записывается время. Поэтому
повторные проходы не дублируют сообщение. При ошибке VK поле остаётся пустым,
и следующий проход повторит отправку.

Ручной `POST /api/transactions/{id}/retry` очищает `failure_notified_at`. Если
повторная обработка снова завершится ошибкой, будет отправлено новое
уведомление.

`FAILURE_ALERT_BATCH_SIZE` ограничивает число уведомлений за один проход;
значение по умолчанию — 20.
