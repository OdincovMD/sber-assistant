# Защита API

Все финансовые маршруты `/api/*` можно закрыть единым API-ключом.
Health-check маршруты `/health*` остаются публичными для Docker и Nginx.

## Включение

Сгенерируйте случайный ключ и сохраните его только в `.env`:

```bash
openssl rand -hex 32
```

```dotenv
API_KEY=<результат команды>
```

После перезапуска каждый запрос к `/api/*` должен содержать заголовок:

```http
X-API-Key: <ваш ключ>
```

Передавайте ключ только по HTTPS: обычный HTTP не защищает заголовок от
перехвата в сети.

Например, в iOS Shortcuts добавьте `X-API-Key` в заголовки запроса к
`POST /api/sber-webhook`.

Если `API_KEY` отсутствует или пуст, проверка отключена для обратной
совместимости. Для сервиса, доступного из интернета, этот режим использовать
не следует.
